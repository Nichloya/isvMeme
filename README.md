# Stvoritelnik směšnyh obrazok
je Medžuslovjansky generator memov, ktory je izdělany na JS i HTML, s ekrannoju tipkovnicoju s medžuslovjanskymi symbolami. Aplikacija je adaptovana dlja poddržky smartfonov.
